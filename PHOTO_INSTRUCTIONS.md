# Adding Your Profile Photo

1. Take any photo of yourself (JPG or PNG)
2. Rename it exactly to: profile.jpg
3. Place it inside the `public/` folder:
   harshita-vite/public/profile.jpg

That's it — the site will automatically show your photo in the sidebar.

If no photo is found, it shows "HG" as a fallback — so the site still looks good either way.

# Running the site
cd harshita-vite
npm install
npm run dev
→ Open http://localhost:5173
